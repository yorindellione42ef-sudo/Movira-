# Contributing to Movira

Thank you for considering contributing to the Movira project! We welcome contributions of all types, and we encourage you to get involved. Below are some guidelines and information on our development workflow.

## Contribution Guidelines

1. **Fork the Repository**: Start by forking the repository to your own GitHub account.

2. **Clone Your Fork**: Clone your forked repository locally:
   ```bash
   git clone https://github.com/your-username/Movira.git
   ```

3. **Create a Branch**: Create a new branch for your work so that your contributions can be tracked separately:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make Changes**: Implement your changes and make sure to commit them with a clear message describing what you’ve done:
   ```bash
   git commit -m "Add a description of your changes"
   ```

5. **Push Your Changes**: Push your changes back to your forked repository:
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Open a Pull Request**: Go to the original repository and open a pull request from your forked repository. Be sure to include a clear description and reference any related issues.

## Development Workflow

- **Continuous Integration**: We use continuous integration tools to ensure that all tests pass before merging changes. Please make sure to run the tests locally to verify everything works before submitting your pull request.
- **Code Reviews**: All pull requests will be reviewed by at least one team member. Feedback may be provided, and changes requested before merging.
- **Stay Updated**: Regularly pull the latest changes from the main repository to keep your fork up to date:
  ```bash
  git pull upstream main
  ```

Thank you for contributing to Movira! We're excited to see your contributions!
